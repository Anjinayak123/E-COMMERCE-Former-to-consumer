# E-Commerce Product Page Simulation (Flask)

## Overview

This project is a Flask-based e-commerce product page simulation with user authentication, cart, checkout simulation, product reviews, search, and category filtering.

## Features

- Product listing with pagination (10 per page)
- Product detail view with image, description, average rating, and reviews
- User registration and login with password hashing
- Session-based cart simulation (add, update, remove items)
- Checkout summary and order placement simulation
- Product ratings and reviews by logged-in users
- Search products by name and filter by categories
- Flash messages for user actions
- Bootstrap 5 for responsive UI

## Requirements

- Python 3.8+
- SQLite
- Recommended: virtualenv
